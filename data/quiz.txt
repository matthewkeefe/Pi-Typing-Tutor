# Pi Typing Tutor -- Whisker Quiz questions
#
# The cat asks; the kid types the answer. This file is meant to be edited.
# Delete everything below and put your own spelling list in -- that's the
# point of it. Same idea as data/passages.txt.
#
# FORMAT
#   question|answer               one per line
#   question|answer1;answer2      any listed answer is accepted
#
#   Blank lines and lines starting with '#' are ignored. Matching is
#   case-insensitive and ignores leading/trailing spaces, so "Cat" and
#   " cat " both match "cat". Malformed lines (no '|', empty question, or
#   empty answer) are skipped rather than crashing the mode. An empty file
#   simply hides Whisker Quiz from the menu.
#
# WRITING GOOD ONES
#   Keep answers SHORT -- one or two words. The kid is typing them, and a
#   long answer turns a quiz into a transcription drill, which is what
#   every other mode already does.
#
#   Prefer answers a kid can reason out over ones they must already know.
#   Add alternates generously; "8" and "eight" are both right, and being
#   marked wrong on a technicality is the fastest way to lose a 7-year-old.
#
# THIS DEFAULT SET
#   A starting point, not a curriculum: cat facts, animals, everyday
#   science, numbers, and a little spelling. Roughly ages 6-11. Swap it
#   out for whatever your kid is actually working on this term.
